# Anki 词汇牌库（15000 词）设计文档

日期：2026-08-17

## 背景与目标

用户考完雅思后，希望扩充英语词汇量到 15000 左右。在 Anki 中新建词汇牌库，参照之前雅思词汇牌组的做法（单词/音标/释义/语音四字段），但背面释义升级为「多义项中文释义 + 例句（含翻译）」，并保留每词语音。

### 之前牌组做法（已解包 `所有牌组.apkg` 确认）

- 3 个牌组：IELTS 核心/扩展/场景词汇，共 4490 词
- 笔记类型「IELTS 词汇卡片 (含音标+音频)」，4 字段：单词 / 音标 / 释义(简) / 语音 `[sound:单词.mp3]`

## 需求决策（已与用户确认）

| 项 | 决定 |
|---|---|
| 词表来源 | 通用词频表（ECDICT `frq` 当代语料库/COCA 排名前 15000） |
| 背面内容 | 多义项中文释义 + 例句（含翻译） |
| 发音 | 美音（音频用 edge-tts 生成） |
| 音标文字 | 英音音标（ECDICT 自带） |
| 牌组划分 | 3 段（每 5000） |
| 例句范围 | 仅前 5000 高频词配例句，后 10000 词仅详细释义 |

## 方案设计

### 1. 牌组结构（3 个）

| 牌组名 | 词频范围 | 例句 |
|---|---|---|
| 高频词汇 1-5000 | COCA 前 5000 | ✅ 每词 1 例句 + 翻译 |
| 中频词汇 5001-10000 | 5001~10000 | ❌ 仅释义 |
| 低频词汇 10001-15000 | 10001~15000 | ❌ 仅释义 |

### 2. 笔记类型（统一 5 字段）

| 字段 | 内容示例 | 来源 |
|---|---|---|
| 单词 | `ability` | ECDICT `word` |
| 音标 | `/əˈbɪləti/` | ECDICT `phonetic`（英音） |
| 释义 | `n. 能力；才能`（多义项、词性分列） | ECDICT `translation` |
| 例句 | `She has the ability to learn quickly.｜她学得快。` | LLM 生成（仅前 5000 词，后 1 万留空） |
| 语音 | `[sound:ability.mp3]` | edge-tts 美音 |

背面模板用条件渲染 `{{#例句}}…{{/例句}}`，3 个牌组共用同一笔记类型。

### 3. 技术链路

```
① 下载 ECDICT 词典数据
② 按 frq 词频升序取前 15000 词
③ 按词频分 3 段（每 5000）
④ 前 5000 词：LLM 批量生成例句 + 中文翻译
⑤ 全部 15000 词：edge-tts 生成美音 mp3（文件名=单词.mp3）
⑥ genanki 打包成 .apkg
⑦ 用户导入 Anki
```

### 4. 产出物与成本

- **产出**：3 个 `.apkg`（或 1 个含 3 子牌组的 `.apkg`），15000 词 + 15000 个美音 mp3
- **例句成本**：5000 词 LLM 生成，分批进行
- **音频成本**：edge-tts 免费在线 TTS，15000 次请求需加延时/重试防限流，耗时较长

### 5. 风险与应对

- edge-tts 批量请求可能被限流 → 加随机延时、失败重试、断点续传（记录已生成清单）
- ECDICT 部分词条 frq 为空（未收录词频）→ 过滤掉无词频词，保证 15000 词均为有排名的高频词
- 音标英音与美音个别词有差异 → 已与用户确认接受英音音标

## 不做的事（YAGNI）

- 不做英英释义、近反义词、词根词缀（用户未选）
- 不保留词形变化（exchange）、柯林斯星级等 ECDICT 附加字段进牌组
- 不做英美双音标/双音频
